# 로드맵

Mochi Keys가 어디로 가는지 적어 둔 문서입니다. 날짜 약속이 아니라 방향과 순서입니다. 버전 번호는 묶음을 구분하려고 붙인 것이고, 실제로는 준비된 것부터 나갑니다.

## 원칙

1. **타이핑 감각이 먼저입니다.** 누르는 순간의 반응, 손에 맞는 배치, 예측 가능한 동작을 기능 수보다 앞에 둡니다.
2. **친 그대로 입력합니다.** 자동 수정과 단어 추천은 넣지 않습니다. 키보드가 사용자의 글을 고치지 않습니다.
3. **기기 밖으로 아무것도 보내지 않습니다.** 네트워크 권한을 추가하지 않습니다. 이 원칙과 충돌하는 기능은 만들지 않습니다.
4. **권한은 최소로.** 기본 상태에서는 진동 말고 아무 권한도 쓰지 않습니다. 권한이 필요한 기능은 기본으로 끄고, 사용자가 내용을 알고 직접 켤 때만 동작하게 합니다. 그때도 가장 좁은 권한을 고릅니다.
5. **기본값은 조용하게.** 소리, 화려한 효과, 알림은 기본으로 꺼 둡니다.

## 지금 어디까지 왔나

- 영어(QWERTY), 한국어(두벌식), 일본어(かな 플릭 + 한자 변환)
- 터치다운 팝업, 터치업 입력, 롤오버, 길게 눌러 변형 문자, 스페이스 트랙패드, 지구본 언어 메뉴
- 이모지 패널과 검색, 얼굴 문자
- 라이트/다크, 클릭음, 진동, 설정 화면
- GitHub Releases와 Obtainium을 통한 배포

## 버전별 계획

### 0.1.x — 실제 폰에서 쓸 만하게

지금까지 대부분 에뮬레이터에서 만들었습니다. 실제 기기에서 드러나는 문제를 먼저 잡습니다.

- [ ] 화면 크기에 맞는 키보드 크기 확인 (0.1.1에서 폭 비례로 조정)
- [ ] 시스템의 키보드 내리기·전환 버튼과 지구본·마이크의 겹침 해소 확인 (0.1.1에서 수정)
- [ ] 진동 세기와 클릭음 지연을 실기기에서 측정하고 맞추기
- [ ] 설정을 바꾸면 키보드를 다시 열지 않아도 바로 반영
- [ ] 만들기만 하고 눌러 보지 못한 동작 점검: 일본어 `空白` 다음 후보, `→`·`↺`, 토글 입력, 한국어 이모지 검색, 후보 격자 스크롤
- [ ] 자동 릴리스(GitHub Actions)가 끝까지 도는지 확인
- [ ] 앱 안의 오픈소스 라이선스 화면(Mozc, Unicode CLDR)

### 0.2 — 인증 코드와 자동 채우기

로그인할 때 가장 자주 부딪히는 불편을 없앱니다. **문자 권한 없이** 합니다.

- [ ] **인증 코드 자동 제안** — 문자로 온 인증 코드를 키보드 위에 띄우고, 누르면 입력. 기기 환경이 제각각이라 세 가지 경로를 둡니다.
  1. **자동 채우기 경로** — 안드로이드의 인라인 자동 채우기(Android 11+)로 받습니다. 코드를 읽는 것은 시스템의 자동 채우기 서비스이고, 키보드는 받은 제안을 보여 주기만 합니다. 추가 권한이 없습니다. 자동 채우기 서비스가 인증 코드를 지원할 때만 동작합니다(예: Google 자동 완성).
  2. **클립보드 경로** — 문자 앱의 알림에서 "코드 복사"를 누르면, 키보드가 복사된 코드를 알아보고 제안 줄에 띄웁니다. 추가 권한이 없고 자동 채우기 서비스가 없어도 됩니다. 한 번 더 눌러야 한다는 점이 다릅니다.
  3. **문자 수신 경로(선택)** — 자동 채우기 서비스를 쓰지 않는 환경(GrapheneOS 등)을 위한 것입니다. 사용자가 설정에서 직접 켜고 문자 수신 권한을 허용하면, 새로 도착한 문자에서 코드를 찾아 제안합니다.
     - 기본으로 꺼져 있고, 켜기 전에 무엇을 읽는지 설명합니다.
     - 새 문자가 도착하는 순간에만 받는 권한(`RECEIVE_SMS`)만 씁니다. 받은 문자함을 읽는 권한(`READ_SMS`)과 보내는 권한은 쓰지 않습니다.
     - 코드처럼 보이는 숫자만 뽑아 메모리에 몇 분 들고 있다가 버립니다. 문자 내용은 저장하지 않습니다.
     - 앱에 네트워크 권한이 없으므로 읽은 내용이 기기 밖으로 나갈 길이 없습니다.
     - 알림 접근은 쓰지 않습니다. 모든 앱의 알림을 볼 수 있어 범위가 더 넓기 때문입니다.
     - 문자가 아닌 경로로 오는 코드(메신저 알림, RCS 채팅, 이메일)는 이 경로로 받을 수 없습니다. 그때는 클립보드 경로를 씁니다.
- [ ] **비밀번호·아이디 제안** — 같은 통로로 비밀번호 관리자(Google, Bitwarden, 1Password 등)의 제안을 키보드 위에 표시
- [ ] **주소·카드·이메일 제안** — 자동 채우기 서비스가 주는 항목 표시
- [ ] 제안 줄: 평소에는 숨겨 두고 제안이 있을 때만 키 위에 나타남. 영어·한국어에서도 같은 자리 사용
- [ ] 인증 코드 칸(숫자 4~8자리)에서 숫자 패드 자동 표시
- [ ] 비밀번호 칸에서 키 팝업 숨기기, 클릭음 구분 없애기(어깨너머 노출 방지)
- [ ] 제안 줄을 끄는 설정

### 0.3 — 입력 칸에 맞는 자판

- [ ] 숫자 칸: 큰 숫자 패드(0~9, 소수점, 부호)
- [ ] 전화번호 칸: 전화 패드(`*`, `#`, `+`, 일시 정지)
- [ ] 주소 칸: `.`, `/`, `.com` 키. `.com`을 길게 누르면 `.net`, `.org`, `.kr`, `.jp`
- [ ] 이메일 칸: `@`, `.` 키
- [ ] 날짜·시간 칸: 구분 기호 키
- [ ] 리턴 키: 보내기·다음·완료·이동의 아이콘과 색, 여러 줄 칸에서의 줄바꿈
- [ ] 앱이 요청한 대문자 방식(문장·단어·전체) 따르기
- [ ] "추천 없음"으로 표시된 칸에서 일본어 학습 끄기
- [ ] 가로 모드 배치(키 높이 축소, 양쪽 여백)

### 0.4 — 입력 방식 채우기

**일본어**
- [ ] 일본어 판 안의 영문 12키(`ABC`)와 숫자·기호 12키(`☆123`)
- [ ] 로마지 입력(QWERTY)
- [ ] 플릭만 사용(토글 입력 끄기) 설정
- [ ] 후보: 반각·전각 변환, 숫자·날짜·시각 후보, 읽기 표시
- [ ] 문절 단위로 나눠 변환 범위 조정
- [ ] 단어 등록(사용자 사전), 학습 기록 지우기
- [ ] `や` 키의 `「」`, 기호 키 변형 보강
- [ ] 얼굴 문자 목록 확장과 분류

**한국어**
- [ ] 천지인(10키)
- [ ] 단모음 자판, 나랏글 등 다른 10키 방식 검토
- [ ] 한자 변환(음을 치고 한자 고르기)
- [ ] 옛한글·특수 자모는 범위 밖

**영어·공통**
- [ ] Shift를 누른 채 다른 키를 누르는 동시 입력
- [ ] `123`을 누른 채 기호로 밀고 떼면 글자판으로 복귀
- [ ] 기호 뒤 스페이스에서 글자판으로 복귀
- [ ] 백스페이스를 오래 누르면 단어 단위로 지우기
- [ ] 길게 눌러 나오는 기호 보강(따옴표 종류, 대시, 통화 기호, 도 기호 등)
- [ ] 스마트 구두점(곧은 따옴표를 둥근 따옴표로) — 기본 꺼짐

### 0.5 — 편집과 클립보드

- [ ] 스페이스 트랙패드의 위아래 이동, 가속
- [ ] 트랙패드 중 두 번째 손가락으로 선택 시작
- [ ] 실행 취소·다시 실행
- [ ] 편집 줄: 전체 선택, 복사, 잘라내기, 붙여넣기, 커서 한 칸 이동
- [ ] 복사한 내용을 한 번에 붙여넣는 제안(제안 줄에 표시)
- [ ] 클립보드 기록 — 기기 안에만 저장, 기본 꺼짐, 비밀번호 칸에서 복사한 것은 제외, 자동 삭제 시간
- [ ] 자주 쓰는 문구(텍스트 대치): 줄임말을 치면 제안 줄에 표시. 자동으로 바꾸지는 않음
- [ ] 스페이스를 좌우로 밀어 언어 전환(선택 사항)

### 0.6 — 모양과 손맛

- [ ] 테마: 색 선택, 기기 배경화면 색 따르기(Material You)
- [ ] 반투명(유리) 질감 — 지원 기기에서 뒤 화면 흐림, 아니면 색조로 근사
- [ ] 키 모양(모서리, 간격, 테두리), 키 높이·폭·아래 여백 세부 조정
- [ ] 글꼴 선택과 크기
- [ ] 키 팝업 끄기, 변형 문자 표시 방식
- [ ] 진동: 세기 단계, 키 종류별 패턴, 기기의 진동 기능에 맞춘 선택
- [ ] 클릭음: 음높이·길이 조절, 다른 음색 묶음
- [ ] 누름 시간(길게 누르기, 반복 시작, 반복 속도) 조절
- [ ] 키보드가 올라오고 내려가는 움직임
- [ ] 설정 내보내기·가져오기(파일)
- [ ] 직접 그린 앱 아이콘

### 0.7 — 큰 화면과 다른 자세

- [ ] 한 손 모드(왼쪽·오른쪽으로 붙이기, 크기 조절)

- [ ] 태블릿: 넓은 배치, 숫자 줄, 양쪽 Shift

### 0.8 — 언어 확장

- [ ] 자판을 코드가 아닌 데이터로 정의(언어 추가를 쉽게)
- [ ] 언어별로 따로 받는 구조 검토(APK 크기 줄이기)
- [ ] 라틴 문자 언어 묶음: 프랑스어(AZERTY), 독일어(QWERTZ), 스페인어, 포르투갈어, 이탈리아어 등 — 자판과 변형 문자만
- [ ] 중국어 간체(병음), 번체(주음·창힐) — 변환 엔진 선정이 먼저
- [ ] 그 밖의 언어는 요청을 보고 정합니다. 변환 엔진이 필요한 언어는 오픈소스 엔진이 있는 것부터.
- [ ] 언어별 숫자·기호판, 통화 기호

- [ ] 지연 측정: 터치에서 화면 반응까지, 터치에서 소리까지. 기기별 기준값 기록
- [ ] 키보드가 처음 뜨는 시간, 메모리, 배터리 점검

### 1.0

아래가 모두 되면 1.0으로 부릅니다.

- 실제 기기 여러 종에서 일상적으로 쓸 수 있음(Pixel, Galaxy 포함)
- 세 언어의 입력 방식이 빠진 것 없이 갖춰짐
- 인증 코드와 비밀번호 제안이 안정적으로 동작
- 입력 칸 종류에 맞는 자판이 모두 있음
- 접근성 기본 항목 충족
- 설정 화면과 안내 문구가 영어·한국어·일본어로 제공됨
- 알려진 충돌 없음

## 1.0 이후

방향만 적어 둡니다.

- 더 많은 언어와 변환 엔진
- 손글씨 입력(기기 안에서 인식)
- 기기 안에서 도는 음성 받아쓰기 — 좋은 오픈소스 엔진이 생기고 용량이 감당될 때
- 시계·자동차·TV 화면은 범위 밖으로 두되, 요청이 많으면 검토
- 다른 키보드에서 설정·사용자 사전 가져오기
- 테마 공유(파일로 주고받기)

## 분야별 장기 과제

버전에 묶이지 않고 계속 가는 일입니다.

**타이핑 감각**
- 기기별 터치 지연과 화면 주사율에 맞춘 반응 조정
- 터치 위치 보정: 손가락이 실제로 닿는 위치와 의도한 키의 차이를 줄이기(글자를 바꾸는 자동 수정이 아니라, 어느 키로 인식할지의 문제)
- 키 가장자리·모서리 터치 처리 다듬기
- 빠른 양손 입력에서의 순서 보장

**일본어 엔진**
- Mozc 새 버전 따라가기, 사전 갱신
- 라이브러리와 사전을 직접 빌드하는 재현 가능한 절차
- 변환 품질 문제 모으기

**개인정보와 보안**
- 권한 추가 금지 원칙 유지, 릴리스마다 권한 목록 확인
- 비밀번호 칸에서 학습·클립보드·화면 표시 최소화

## 하지 않는 것

- 자동 수정, 단어 추천, 다음 단어 예측 — 일본어의 한자 변환 후보는 입력에 꼭 필요한 것이라 예외입니다.
- 스와이프 타이핑
- 네트워크를 쓰는 기능: 클라우드 동기화, 온라인 사전, GIF·스티커 검색, 번역, 웹 검색
- 계정, 광고, 사용 통계 수집
- 연락처·저장소·알림 접근 권한을 쓰는 기능, 받은 문자함 읽기와 문자 보내기 — 인증 코드용 문자 수신만 사용자가 켰을 때 예외입니다.
- 글쓰기 보조(문장 고쳐 쓰기, 요약 등)

## 알려진 한계

- 비밀번호 제안은 기기의 자동 채우기 서비스가 제공하는 만큼만 동작합니다. 인증 코드는 자동 채우기 서비스가 없으면 클립보드 경로나 문자 수신 경로를 써야 합니다.
- 일본어 변환은 Mozc 엔진의 품질을 그대로 따릅니다.
- 이모지 그림은 기기의 것을 씁니다. 기기에 없는 이모지는 목록에서 빠집니다.
- 일부 앱(웹 브라우저 등)은 조합 중인 글자에 자체 밑줄을 그립니다.
- 시스템이 그리는 키보드 내리기·전환 버튼은 없앨 수 없습니다.
- 뒤 화면이 비치는 유리 질감은 안드로이드에서 제한적으로만 가능합니다.
- arm64 말고 다른 CPU용 APK는 빌드만 확인했고 실제 기기에서 돌려 보지 못했습니다.
